# 簿記3級 第24回 50問｜振り返り

ふくしままさゆき「簿記3級　本試験レベル（？）問題50問！㉔/25」を解いたときの振り返りページです。
全50問の問題文・正解・解説、論点別の正答率、間違いの型をまとめています。
正解と解説は折りたたんであるので、解き直しにそのまま使えます。

- 公開ページ：`index.html` の1ファイルだけで動きます（ビルド不要・外部読み込みなし）
- 検索エンジンには出ないよう `noindex` を指定しています

## 更新のしかた

このページは手書きではなく、手元の学習記録（`第24回-復習記録.md`）から
`tools/build_review_site.py` で生成しています。どちらもこのリポジトリには含めていません。

記録を直したら生成スクリプトを実行し、出力された `index.html` をコミットします。

```
python tools/build_review_site.py
npx html-validate review-site/index.html
```
